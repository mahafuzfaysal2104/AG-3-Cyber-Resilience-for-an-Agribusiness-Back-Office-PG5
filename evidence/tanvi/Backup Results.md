## Backup Detection on MON01  
MON01 uses Wazuh to monitor backup results generated by APP01. After each scheduled Restic backup to the MinIO server on BKP01, APP01 records either a BACKUP_SUCCESS or BACKUP_FAILED message. The Wazuh agent forwards these logs to MON01, where custom rules classify them and display alerts on the backup dashboard. During testing, MON01 recorded five successful and four failed backup events. This monitoring allows the team to identify backup problems quickly without installing a Wazuh agent directly on BKP01.
